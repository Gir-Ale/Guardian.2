# Guardian.2

Computer Driven FPV Walker



Here you can find a 3mf file to 3D print the robot, as well as the list of parts needed to build it, the electronic diagram, and the code to flash the ESP's and drive the system.



Parts needed: 

* 2 DC gear motor
* 2 9g servomotors
* 1 7.4 V to 5v buck convertor
* 1 ESP-CAM with and antenna
* 1 Xiao ESP32
* 1 2S 7.4V BMS
* 1 2S 7.4V Li-ion battery pack
* 1 I2C audio amplifier
* 1 speaker
* 50 M3 screws and nuts 
* 4 M3 rods
* 500g of PLA
